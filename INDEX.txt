⚡ COMMANDES RAPIDES
═════════════════════════════════════════════════════════════════════════════════

LANCER LE SERVEUR:

   python -m http.server 8000
   # puis: http://localhost:8000

   npm start
   # ou: npm install && npm start

   npx http-server . -p 8000
   # puis: http://localhost:8000


GÉNÉRER LES ICÔNES:

   # Via navigateur:
   Ouvrir: http://localhost:8000/generate-icons.html

   # Via Node.js:
   npm install sharp
   npm run generate-icons
   # ou directement:
   node scripts/generate-icons.js


TESTER (Chrome DevTools):

   F12 > Application > Service Workers .......... Voir si enregistré
   F12 > Application > Manifest ................ Voir si valide
   F12 > Application > Cache Storage ........... Voir fichiers en cache
   F12 > Console > (taper les commandes ci-dessous):

   navigator.serviceWorker.getRegistrations()
   fetch('./manifest.json').then(r => r.json()).then(m => console.log(m))
   caches.keys().then(keys => console.log('Caches:', keys))
