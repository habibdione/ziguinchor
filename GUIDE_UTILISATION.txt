   🗺️  UTILISER LA GÉOLOCALISATION
█████████████████████████████████████████████████████████████████████████████

BOUTON DE GÉOLOCALISATION: 📍

  1. Cherchez le bouton "📍 Ma position" dans l'interface
  
  2. PREMIÈRE UTILISATION
     • Vous verrez une demande: "Autoriser la géolocalisation?"
     • Cliquez "Autoriser" ou "Allow"
     • Attendez quelques secondes
  
  3. RÉSULTATS
     ✓ Un point bleu apparait sur la carte = votre position
     ✓ Un cercle gris = zone de précision (±X mètres)
     ✓ Un popup avec:
       - Votre latitude
       - Votre longitude
       - Précision estimée
       - Heure actuelle
  
  4. BOUTON "Copier coord."
     • Cliquez pour copier les coordonnées en format texte
     • Prêt à partager ou intégrer ailleurs
  
  5. ARRÊTER LE SUIVI
     • Le bouton devient "📍 Arrêter le suivi"
     • Cliquez pour arrêter
     • Le marker disparait de la carte
  
  6. HISTORIQUE
     • Toutes vos positions sont sauvegardées localement
     • Accessible même après fermeture de l'app
     • Jusqu'à 100 positions gardées

   🆘 AIDE RAPIDE
█████████████████████████████████████████████████████████████████████████████

❌ "L'app ne s'installe pas"
   → Vérifiez HTTPS (ou localhost)
   → Videz cache: Ctrl+Shift+Del
   → Rechargez: Ctrl+F5
   → Consultez: PWA_INSTALLATION.md > Dépannage

❌ "La géolocalisation ne marche pas"
   → Vérifiez permission navigateur
   → Vérifiez GPS activé sur mobile
   → Attendez 10 secondes
   → Consultez: CHECKLIST_PWA.md > Dépannage

❌ "L'app est lente"
   → Videz cache application
   → Vérifiez connexion réseau
   → Testez en mode incognito
   → Redémarrez l'app

❌ "Service Worker ne s'enregistre pas"
   → F12 > Application > Service Workers
   → Devrait afficher: "running"
   → Sinon, consultez console pour erreurs
   → Vérifiez sw.js existe à la racine
