🚀 DÉMARRER MAINTENANT
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Lancer un serveur local
────────────────────────────────

Option A - Python 3:
  python -m http.server 8000
  → Accédez à: http://localhost:8000

Option B - Node.js:
  npm start
  → Accédez à: http://localhost:8080

Option C - HTTP Server:
  npx http-server . -p 8000
  → Accédez à: http://localhost:8000

ÉTAPE 2: Générer les icônes PWA
────────────────────────────────

Méthode A - Via Navigateur (RECOMMANDÉ):
  1. Ouvrez: http://localhost:PORT/generate-icons.html
  2. Cliquez "Générer les fichiers"
  3. Les PNG s'installent dans images/

Méthode B - Via Node.js:
  npm install sharp
  npm run generate-icons
  # ou
  node scripts/generate-icons.js

ÉTAPE 3: Tester localement
──────────────────────────

  1. Ouvrez: http://localhost:PORT
  2. Appuyez F12 (DevTools)
  3. Allez à: Application > Service Workers
  4. Devrait afficher: ✅ running
  
  5. Allez à: Application > Manifest
  6. Devrait afficher: ✅ Valid
  
  7. Allez à: Application > Cache Storage
  8. Devrait afficher: ✅ geoziguinchor-v2.0.0

ÉTAPE 4: Tester la géolocalisation
───────────────────────────────────

  1. Cherchez le bouton "📍 Ma position"
  2. Cliquez dessus
  3. Autorisez la géolocalisation
  4. Vous devez voir votre position sur la carte
  5. Cercle de précision visible
  6. Popup avec détails affichée

ÉTAPE 5: Tester l'installation
───────────────────────────────

Sur Android - Chrome:
  1. Attendez la notification d'installation (5-10s)
  2. Cliquez "Installer"
  3. Confirmez
  → L'app s'ajoute à l'écran d'accueil

Sur Chrome Desktop:
  1. Cherchez l'icône d'installation 🔧
  2. Cliquez
  3. Confirmez
  → Un raccourci s'ajoute au bureau

🌐 CONFIGURATION SERVEUR RECOMMANDÉE
═══════════════════════════════════════════════════════════════════════════════

APACHE (.htaccess):
────────────────
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

<FilesMatch "\.(sw|js|css|jpg|png|gif|svg)$">
  Header set Cache-Control "max-age=31536000, public"
</FilesMatch>

<FilesMatch "\.html$">
  Header set Cache-Control "max-age=3600, must-revalidate"
</FilesMatch>

NGINX:
──────
server {
    listen 443 ssl http2;
    server_name votre-domaine.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    add_header 'Service-Worker-Allowed' '/';
    
    location ~* \.(sw|js|css)$ {
        expires 365d;
        add_header Cache-Control "public, immutable";
    }
    
    location ~* \.html$ {
        expires 1h;
        add_header Cache-Control "public, must-revalidate";
    }
}

🆘 DÉPANNAGE RAPIDE
═══════════════════════════════════════════════════════════════════════════════

❌ L'app ne s'installe pas
   → Vérifiez HTTPS (ou localhost)
   → Videz cache navigateur (Ctrl+Shift+Del)
   → Rechargez (Ctrl+F5)
   → Vérifiez manifest.json est valide
   → Vérifiez icônes existent (192x192, 512x512)

❌ Service Worker ne s'enregistre pas
   → Vérifiez que sw.js existe à la racine
   → Vérifiez dans DevTools > Application > SW
   → Console: navigator.serviceWorker.getRegistrations()
   → Videz cache et rechargez

❌ La géolocalisation ne fonctionne pas
   → Vérifiez permissions du navigateur
   → Vérifiez GPS activé sur l'appareil
   → Console: 'geolocation' in navigator (doit être true)
   → Testez en haute précision

❌ L'app est lente hors ligne
   → Vérifiez que l'appareil a d'abord chargé la page en ligne
   → Service Worker doit être enregistré et actif
   → Cache doit contenir les fichiers

→ Consultez CHECKLIST_PWA.md pour tests détaillés
