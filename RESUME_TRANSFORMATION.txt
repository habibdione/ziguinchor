4️⃣  DÉMARRAGE RAPIDE (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: Lancer un serveur
  
  Option A (Python 3):
    python -m http.server 8000
  
  Option B (Node.js):
    npm start
  
  Option C (http-server):
    npx http-server . -p 8000

ÉTAPE 2: Générer les icônes
  
  Ouvrez dans navigateur:
    http://localhost:PORT/generate-icons.html
  
  Cliquez: "Générer les fichiers"

ÉTAPE 3: Tester
  
  Ouvrez:
    http://localhost:PORT
  
  Appuyez F12 (DevTools):
    Application > Service Workers ........... ✅ Should show running
    Application > Manifest ................. ✅ Should show Valid
    Application > Cache Storage ............ ✅ Should show cached files

ÉTAPE 4: Tester sur mobile
  
  Android - Chrome:
    • Attendez 5-10 secondes
    • Cliquez "Installer" dans la notification
    • Confirmez
  
  iOS - Safari:
    • Bouton partage (⬆️)
    • "Ajouter à l'écran d'accueil"
    • Confirmez

8️⃣  DÉPLOIEMENT EN PRODUCTION
═══════════════════════════════════════════════════════════════════════════════

PRÉREQUIS:

  ✓ HTTPS activé (certificate SSL/TLS)
  ✓ Service-Worker-Allowed header configuré
  ✓ Cache headers configurés
  ✓ Icônes PNG générées dans images/


FICHIERS À DÉPLOYER:

  - index.html
  - manifest.json
  - sw.js
  - js/ (dossier complet)
  - css/ (dossier complet)
  - data/ (dossier complet)
  - images/ (y compris les icônes PNG générées)
  - scripts/ (optionnel)
  - generate-icons.html (optionnel)


CONFIGURATION SERVEUR (Apache .htaccess):

  RewriteEngine On
  RewriteCond %{HTTPS} off
  RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
  
  <FilesMatch "\.(sw|js|css)$">
    Header set Cache-Control "max-age=31536000, public"
  </FilesMatch>
  
  <FilesMatch "\.html$">
    Header set Cache-Control "max-age=3600, must-revalidate"
  </FilesMatch>

9️⃣  DÉPANNAGE COURANT
═══════════════════════════════════════════════════════════════════════════════

❌ Service Worker ne s'enregistre pas

   CAUSES POSSIBLES:
   → HTTPS non activé (requiert localhost ou HTTPS)
   → Service Worker path incorrect
   → JSON invalide dans manifest.json
   → Erreurs console (F12)
   
   SOLUTIONS:
   → Vérifiez HTTPS ou utilisez localhost
   → Vérifiez que sw.js est à la racine
   → Validez manifest.json avec JSONLint
   → Consultez console pour erreurs


❌ L'app ne s'installe pas sur mobile

   CAUSES POSSIBLES:
   → Icons 192x192 ou 512x512 manquantes
   → Display mode invalide
   → Scope incorrect
   → Cache non créé
   
   SOLUTIONS:
   → Générez icônes avec generate-icons.html
   → Vérifiez display: "standalone"
   → Vérifiez scope: "./"
   → Videz cache du navigateur


❌ Géolocalisation demande permission mais ne fonctionne pas

   CAUSES POSSIBLES:
   → Permission non autorisée
   → GPS désactivé (mobile)
   → Navigateur bloquerait
   
   SOLUTIONS:
   → Autorisez géolocalisation dans paramètres navigateur
   → Activez GPS sur l'appareil
   → Attendez 5-10 secondes
   → Testez avec haute précision
