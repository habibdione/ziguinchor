📖 LIRE CECI EN PREMIER
══════════════════════════════════════════════════════════════════════════════

1. Ouvrez un terminal/PowerShell
2. Tapez UNE ces commandes:

   python -m http.server 8000
   # OU
   npm start
   # OU
   npx http-server . -p 8000

3. Ouvrez dans votre navigateur:
   http://localhost:8000

4. Pour générer les icônes:
   http://localhost:8000/generate-icons.html
   → Cliquez "Générer les fichiers"

5. Testez l'installation sur votre téléphone!
   Android: Attendez notification, cliquez "Installer"
   iOS: Bouton partage → "Ajouter à l'écran d'accueil"


✨ VOILÀ! VOUS AVEZ UNE PWA! ✨
